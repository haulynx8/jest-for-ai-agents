# Changelog

All notable changes to this project are documented here.

## 0.1.0 — 2026-09-27

- Async agent test runner with timeouts, concurrency, and structured results.
- Jest-like registration and expectation API.
- Pluggable correctness, schema, tool-use, and initial security evaluators.
- Adapters, traces, replay baselines, JSON/terminal/CI reporting, and CLI.
- OpenAI Responses API adapter with mock-tested function-call parsing.

## Release policy

This is an alpha release. The public API may change before 1.0.0; changes will
be documented in this file.
